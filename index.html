Personal Drive MCP

Personal Drive MCP is a personal-use software tool operated by a single individual. It connects the operator's AI assistant to the operator's own Google Drive account so the assistant can list, read, download, and organize the operator's own files, only at the operator's direction.

The tool is not offered to the public. It has exactly one user, the operator, and it is not a commercial product. It is not distributed, sold, or made available to anyone else.
